# Changing a course's section, time, or teacher

Open a course's editor by clicking the **pencil** on its row — in the grid, the
day view, the slot list, or the strip below the grid. The editor is where every
setting for one section lives.

<Shot file="schedule-course-editor.png" />

## What you can change

- **Section** — the letter that identifies this class (A, B, …).
- **Instructor** — start from **Department** or **All instructors**, then pick a
  name, or type one.
- **Other instructors** — anyone who co-teaches, separated by commas. Leave it
  blank if there is only one teacher.
- **Meeting time** — three choices:
  - **Time slot** — pick a day group (**MWF** or **TR**) and one of the standard
    times.
  - **Custom time** — type your own **start** and **end** (times snap to
    five-minute steps).
  - **No meeting time** — for independent studies and similar courses.

When you are done, click **Save changes**. **Cancel** closes without saving,
and **Remove course** takes the section off the schedule.

## The day-group rule

If a class meets **MWF** and you switch it to **TR**, the old time no longer
applies, so **Save changes** stays greyed out and a message asks you to **Pick a
time slot for TR.** Choose a TR time and saving is allowed again. The same is
true in reverse.

::: tip
You can also give a course **no meeting time**; it then moves to the strip below
the grid. From there you can drag it onto a time slot later, or open it again
with its pencil.
:::
