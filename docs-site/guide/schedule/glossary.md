# Words used in this app

Plain-language definitions of the labels you will see on screen.

| Word | What it means here |
| --- | --- |
| **offering** | One section or lab of a course. The word appears in headings like **Offerings (3)**. |
| **section** | A single class meeting of a course, identified by a letter (A, B, …). |
| **lab** | A section attached to a lecture. It shares the course, adds an **L** to the number (**BIO 165L**), and numbers its own sections (**A1**, **A2**). |
| **term** | One of **Fall**, **Winter**, or **Spring**. A schedule holds all three; the app shows one at a time. |
| **R** | Thursday. The week is labelled **M T W R F**, and R is Thursday's shorthand. |
| **custom** | A class time that is not one of the standard blocks. Custom meetings show as dashed blocks, and times outside the grid's hours move to the strip below it. |
| **No meeting time** | A course deliberately left off the calendar — independent studies and the like. |
| **session** | The stretch of time you are editing or suggesting, shown by the bar with the **EDITING** or **SUGGESTING** chip. |
| **draft** | Your private working copy during a suggest session. Nothing is written to the schedule until it is proposed and approved. |
| **proposal** (or **suggestion**) | A set of changes sent for the owner to review. |
| **pending / approved / rejected / withdrawn / moot** | A proposal's states: waiting, accepted, turned down, taken back, or no longer applicable. |
| **owner** | The person who created a schedule. Only the owner edits it directly and changes its sharing. |
| **History** | The list of what *you* changed this session, with the option to undo. |
| **reference** | Another shown schedule, dimmed and read-only while you edit one schedule. |
| **Color by schedule / See individual courses** | How several schedules are drawn together: one color each, or every course listed. |
| **filter** | Highlights the departments or teachers you pick; it does not hide the rest, just dims them. |
| **conflict / double-booked** | Two classes at the same time. A **conflict** is between courses; a **double-booking** is a teacher in two places at once. |
| **summary CSV / registrar CSV** | The two spreadsheet downloads: what is on screen now, versus the official one-schedule record. See [Downloading a CSV](/guide/schedule/csv). |
| **Your schedules** | Everything you own or can see — your own, those shared with you, and public ones. |
