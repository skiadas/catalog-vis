# Sharing a schedule and controlling access

By default a schedule is **private** — only you can see it. The lock button on
its row (**Control access to …**) opens the sharing settings. Only the owner can
change them.

<Shot file="schedule-access.png" />

## Two separate questions

**Who can see this schedule?** and **Who can suggest changes?** Each has the
same three choices:

- **Only you** — private.
- **Listed users** — only the people you add.
- **Everyone** — any signed-in user.

With **Listed users** you get a box to type a name or username and click
**Add**. Remove someone with the **×** beside their name.

::: tip
A listed suggester can always see the schedule too. And you never need to grant
edit access to anyone else — only the owner edits a schedule directly. Everyone
else can propose changes.
:::

## What the other person sees

Once you add someone, the schedule appears on their **Your schedules** page
under **Shared with you** (or **Public**, if you chose Everyone). They can then
show it in their own week or start suggesting changes.

## Schedules you do not own

If you open a schedule someone else owns, the access settings show only
**Only the owner can change access for this schedule.** You can still view it
and, if allowed, suggest changes.
