# Adding a course

You add courses inside an editing or suggesting session. If you have not
started one yet, see [Editing vs suggesting](/guide/schedule/edit-vs-suggest).

1. Click **＋ Add course** in the session bar.
2. Start typing a course **code or name** in the search box. The list narrows as
   you type. When you search by department, the app leans toward the
   departments you belong to, but you can still find any course.
3. Click the course section you want.
4. The course editor opens with sensible defaults, ready for you to adjust its
   day, time, teacher, and section. See
   [Changing a course](/guide/schedule/edit-course).

<Shot file="schedule-add-course.png" />

Once you save, the course appears on the grid immediately — in your draft if you
are suggesting, or on the schedule if you are the owner.
